# Roxhers Bozali - Personal Portfolio (Angular 21)

This is the standalone **Angular 21** personal portfolio codebase for Roxhers Bozali, featuring:
- **Angular 21 Zoneless Change Detection**: Zero Zone.js overhead via `provideExperimentalZonelessChangeDetection()`
- **Signals Reactivity**: Fine-grained `signal()`, `computed()`, and `linkedSignal()` primitives
- **Modern Control Flow**: `@if`, `@for`, and `@switch` template syntax
- **Native View Deferral**: `@defer (on viewport)` lazy chunking
- **Typed Reactive Forms**: Built with `NonNullableFormBuilder` and declarative validators
- **Tailwind CSS v4 Integration**: Clean modern utility architecture

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   # or
   ng serve
   ```

3. Open `http://localhost:4200` in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
